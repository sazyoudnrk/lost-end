1. はじめの設定

  1. GitHub で Fine-grained token を作る（Repository access：このリポジトリだけ、Permissions → Contents：Read and write）。
  2. エディタの ☁ Git タブでトークンを貼り付けて「接続テスト」。オーナーとリポジトリ名は URL から自動で入ります。
  3. 「GitHubから読み込み」で最新のデータを取り込みます。
トークンはこの端末のブラウザにだけ保存されます。編集中のデータも端末に自動保存されるので、途中で閉じても消えません。

3. マップを描く

基本操作

  • 下のパレットでタイルをタップ → マップをなぞって描く。
  • 2本指で拡大・移動。⤢ で全体表示に戻る。
  • パレットの「範囲選択」をオンにすると、複数マスをまとめて選べます（大窓・テーブルなど）。

ツール

✏️ペン
▭四角で塗る
🪣同じタイルの範囲を塗りつぶし
🧽消しゴム（今のレイヤーだけ）
💧マップ上のタイルを拾う
🎯EVイベントモード（下の「イベント」参照）
✋1本指でスクロール

レイヤー

  • 下層：床・壁など。中層：家具や小物。上層：さらに重ねる飾り。ここまではキャラクターの後ろに描かれます。
  • 最上：キャラクターより手前に重なるもの（天井の梁、手前の柱、植物の葉など）。
  • 選んでいない層は薄く表示されます。
  • 通れるかどうかは下層と中層のタイルで決まります（素材タブの「通行」で設定）。上層・最上層は見た目だけです。

マップの追加・設定

  • 上の ＋ で新規マップ。⚙ で名前・サイズ・タイルセットの変更、複製、削除。
  • 左上のプルダウンで編集するマップを切り替え。

4. イベントを作る

  • 🎯EV でマップの空きマスをタップ → 「新規イベント」。既存イベントはタップで編集、ドラッグで移動。
  • 空きマスのメニューから「ここからテストプレイ」「プレイヤー開始位置にする」もできます。
  • 「イベント一覧」でマップ内のイベントを一覧表示。
  • イベント編集画面の上の複製で、となりの空きマスに同じイベントを作れます（大きい扉の左右など）。コピーしてから 🎯EV で空きマスをタップすると「ここに貼り付け」が出ます（別のマップにも貼れます）。セルフスイッチは元のイベントとは別々になります。

ページ

1つのイベントに複数のページ（P1, P2…）を持てます。出現条件を満たすページのうち、番号が一番大きいものが使われます。

例：宝箱 … P1「開ける→アイテム入手→セルフスイッチA=ON」、P2（条件：セルフスイッチA=ON）「からっぽだ」。

設定項目

画像なし／歩行キャラ（向き指定）／タイル
トリガー調べる：Aボタン。プレイヤー接触：踏む・ぶつかる。自動実行：条件を満たすとすぐ始まる（条件を外さないと繰り返すので注意）
重なりキャラと同じ：壁のように通れない（NPC・宝箱）。キャラの下：上に乗れる（床のスイッチ・扉・階段）
すり抜けオンにすると通り抜けられる
扉や階段は「プレイヤー接触＋キャラの下」、壁にある扉は「プレイヤー接触＋キャラと同じ」（ぶつかると発動）にすると自然です。

6. データ

  • タイルサイズ：タイルセット画像の1マスのピクセル数（今は48）。
  • 主人公の歩行キャラ・開始マップと位置・開始時の向き。
  • スイッチ／変数：名前を付けておくとイベント編集で選びやすくなります。足りなければ「＋10個追加」。
  • アイテム：名前と説明。ゲーム中はメニュー（☰）→アイテムで確認できます。

遠景と透明なタイル

  • タイルの透明な部分は、エディタではうす紫の市松模様で表示されます（パレット・ドット絵エディタ・素材の一覧）。
  • マップの透明な部分（と、マップの外側）には遠景が見えます。窓のガラス部分を透明にしておくと、窓の向こうに星空が流れて見えます。
  • 遠景は「素材」タブの「遠景」に追加し、マップ設定（⚙）の「遠景」で選びます。
スクロール率0%＝画面に固定、100%＝マップと一緒に動く。20〜50% くらいで奥行きが出ます
自動スクロール1秒に動くドット数。横がマイナスで左へ、縦がマイナスで上へ流れます

遠景の画像は上下・左右の端がつながるように描くと、継ぎ目が見えません。ドット絵エディタの「＋ 新規で描く」でも作れます（初期サイズ 384×384）。

立ち絵とスチル

立ち絵

  • 「素材」→「立ち絵」に追加。表情ごとに1枚ずつ（例：ムロ_通常、ムロ_焦り）。
  • 白い背景の絵は、追加するときに「外側の白い背景を透明にしますか？」で OK を押すと、ふち（上・左・右）からつながった白だけが透明になります。服や目の白は残ります。あとからドット絵エディタの ⋯ →「外側の白を透明に」でもできます。
  • 文章コマンドの「立ち絵」と「位置（左・中央・右）」で、その文章を話すキャラの立ち絵を出します。話し手以外の立ち絵は少し暗くなります。
  • 「そのまま」は前の状態を続ける、「消す」はその位置の立ち絵を消します。
  • 表情を変えるときは、同じ位置で別の立ち絵（ムロ_焦り など）を選ぶだけです。
  • 話していないキャラを並べておきたいときは立ち絵コマンドで出します。
  • イベントが終わると立ち絵は自動で消えます。

スチル

  • 「素材」→「スチル」に追加し、スチルコマンドで表示。画面いっぱいに出て、文章はその上に表示されます。
  • 「消す」を選んだスチルコマンドで消せます。イベントが終わると自動で消えます。

日付・時間帯・等価交換機

日付と時間帯

  • ゲームは 1日目・朝 から始まります。時間帯の名前は「データ」→「日付と時間帯」で変更できます（初期値：朝、昼、夜）。
  • 会話や調査のイベントの最後に時間を進めるを入れると、行動するたびに 朝→昼→夜 と進みます。夜より先には進みません。
  • ベッドなどで次の日へを実行すると、日付が1つ進んで朝に戻ります（画面に「2日目」と表示）。
  • ページの出現条件・条件分岐に日付（＝3日目、≧7日目 など）・時間帯・価値が使えます。
  • ゲーム画面左上に「2日目 朝　価値 10」のように表示されます。「データ」→「日付と時間帯」で、日付・時間帯と価値それぞれ何日目から・どのスイッチがONになったら表示するかを決められます（例：日付は2日目から、価値はスイッチ「価値を知った」がONになってから）。

日ごとの配置（キャラの居場所）

  • イベント編集の「日ごとの配置」に、何日目から何日目まで・時間帯・スイッチ・マップと位置を行で追加します。スイッチを指定すると、そのスイッチがON（またはOFF）のときだけその行が使われます（例：集合イベントが終わるまではエントランス、終わったら各自の場所）。変数の条件も付けられるので、「進行度＝1のときは操縦室の扉の前」のように物語の段階ごとに居場所を決められます。
  • 当てはまる行の場所に出ます。複数当てはまるときは下の行が優先。どの行にも当てはまらないときはどこにもいません。「いない」行で明示的に消すこともできます。
  • 例（ムロ）：「1日目〜・いつでも：操縦室」「2日目〜・朝：エントランス」→ 2日目以降は朝だけエントランスにいて、昼と夜は操縦室。
  • 他のマップに配置されている分は、マップ上に水色の点線で表示されます（ラベルは日付・時間帯）。🎯EV でタップすると元のイベントが開きます。
  • 会話の内容を日ごとに変えるときは、ページを増やして出現条件に「日付」を入れます。

価値と等価交換機

  • 価値はお金のようなもの。「データ」→「等価交換機」の「最初の価値」から始まります。
  • 交換画面は「とりだす」「いれる」の2つのタブで、アイテムがカード（名前・絵・説明・価値）で3列に並びます。カードを押して選び、下のボタンで決定。カードの絵は「素材」→「アイテム画像」に描いて（または追加して）、「データ」→アイテムの「画像」で選びます。
  • アイテムには「交換機に入れたときの価値」を設定します。交換機の入れるでアイテムを価値に変えられます（0のものは入れられない）。
  • イベントで価値の増減を使えば、会話・探索・人間関係で価値を手に入れる仕組みが作れます。
  • 交換機の取り出すには、毎朝品ぞろえ表から抽選された品が並びます。
  • 品ぞろえ表の各行：アイテム、必要な価値、重み（大きいほど出やすい）、出現する日、出現条件のスイッチ、一度きり、取り出し回数を増やす（説明書・アップデート用）。
  • 1日に取り出せる回数を超えると「オーバーヒート中」で取り出せません。翌朝リセットされます。

自由行動の会話（テンプレート）

  • 各キャラ（ムロ・ネイサ・ノノノ・ニノマエ・ピヲラ）のイベントは「○○と過ごす？」→「過ごす／話すだけ」の形になっています。
  • 過ごす：変数「○○と過ごした回数」の値で会話が変わります（0＝1回目、1＝2回目…）。会話のあと回数+1、時間帯が1つ進みます。夜に過ごすとスイッチ「今日はもう遅い」がONになり、それ以降は「もう遅い」と出ます。ベッドで眠るとOFFに戻ります。
  • 話すだけ：ランダム分岐で、どうでもいい会話のどれかが出ます。時間は進みません。
  • 会話を増やすときは「変数で分岐」を開いて「＋ 値を追加」、どうでもいい会話を増やすときは「ランダム分岐」で「＋ 候補を追加」。
  • 特定の日だけの会話は、ページを足して出現条件を「日付＝3」＋「セルフスイッチA が OFF」にし、最後にセルフスイッチAをON（ネイサのP2が見本）。

8. ドット絵エディタ

基本

  • 1本指で描く、2本指で拡大・移動。⤢ で全体表示。
  • 青い線はタイル（歩行キャラならコマ）の区切り。拡大すると1ドットごとのグリッドも出ます。# で表示切替。
  • 歩行キャラを編集中は、右上に歩きアニメのプレビューが出ます。タップで向きを切り替え。
  • 保存すると端末に保存され、☁ でプッシュされます。
  • レイヤーは2枚（1 下／2 上）。「👁 もう1枚」で選んでいない方を表示・薄く・隠すに切り替え。保存すると2枚を重ねた1枚の画像になります（レイヤーの分かれ方はこの端末に記憶され、次に開いたとき戻ります）。
  • 範囲選択中の「レイヤー○へコピー」で、選んだ部分をもう1枚のレイヤーに浮かせて貼れます。浮かせている最中の「→レイヤー○へ」で、もう1枚へそのまま移せます。
  • 範囲選択もアンドゥ（↶）で戻せます。「選択解除」は選択中のバーの先頭にあります。

ツール

✏️ペン（太さ 1〜4）
🪣同じ色の範囲を塗りつぶし。範囲を選択しているときは、その中だけを塗ります（1マスだけ塗りたいときは、⬚でそのマスを選んでから🪣）
／直線
💧色を拾う（透明な所を拾うと「透明」になる）
⬚範囲選択（下の「選択とコピー」）
✋1本指でスクロール

色

黒・白・透明（うす紫の市松模様のボタン）と、色ボックスで選んだ色（使った色は一時的に並びます）。消しゴムの代わりに「透明」を選んでペンで描きます。塗りつぶしや選択範囲の「塗る」でも透明にできます。

トーン

グレーの代わりに、黒と白の2値パターン（6%〜88%の網点、横線・縦線・斜線・格子）で塗れます。ペン・直線・塗りつぶし・選択範囲の「塗る」で使えます。模様は画像全体の座標に合わせて置かれるので、タイルをまたいでもつながります。黒・白・色を選ぶとトーンは解除されます。

選択とコピー

  • ⬚ でドラッグすると範囲選択。🧲吸着がオンだと、マス（コマ）単位で選択・移動します。1マスタップでそのマスを選択。
  • 選択中：コピー／切り取り／貼り付け／左右反転／上下反転／塗る／消す／解除。
  • 選択した中をドラッグすると、その部分を持ち上げて移動できます。
  • ← ↑ ↓ →：選択した部分を1ドットずつ動かします（吸着に関係なく1ドット）。
  • 複製：元を残したままコピーを浮かせます。矢印でずらして「確定」。
  • スタンプ：浮かせている絵を今の位置に押して、浮かせたまま続けます（同じ形を少しずつずらして何個も置くとき）。
  • 例：左右対称にしたいとき … 左半分を選択 → 複製 → ⇋反転 → → で1ドットずつ右へ → 確定。
  • 貼り付け中はドラッグで位置を決めて「確定」。
  • 例：歩行キャラの左向きを描いたら、コピー → 貼り付け → ⇋反転 → 右向きの位置へ移動 → 確定。

⋯ メニュー

  • 画像を読み込んで貼り付け：別のアプリで描いた絵を取り込んで、好きな位置に置く。
  • キャンバスサイズ変更：タイルセットは縦のマス数だけ変更できます（横を変えるとマップのタイル番号がずれるため）。
  • 外側の白を透明に：ふちからつながった白を透明にする（白背景の絵の取り込み用）。
  • 全部消す

9. テストプレイと公開

  • ▶：プッシュ前の内容（新しい素材も含む）で遊べます。マップの空きマスから「ここからテストプレイ」も可能。
  • テストプレイ中は右上の 🐞 でデバッグ画面が開きます。進行度などの変数・スイッチ・日付・価値・主人公の名前・場所を書き換えて「反映してこの場所から再開」。「＋ 今の状態を保存」で名前つきで保存しておくと、次のテストプレイから「読込」ですぐその状態に飛べます。
  • ☁：変更をまとめて1回のコミットでプッシュ。メッセージを付けたいときは Git タブから。
  • 公開ページへの反映は1分ほどかかります。
  • ゲーム操作：十字キーで移動、A で調べる／文章送り、☰ でメニュー（アイテム・セーブ・ロード）。行きたい場所をタップしてもそこまで歩き、人や物をタップすると隣まで歩いて話しかけます。
